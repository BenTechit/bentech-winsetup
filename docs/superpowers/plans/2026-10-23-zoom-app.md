# Zoom as an optional app Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Zoom switch in the toolbox's APPS row (off by default) that installs Zoom per-machine through winget with auto-update on.

**Architecture:** Choices gain a bool key `Zoom`; a new step `zoom`, right after `7zip`, installs `Zoom.Zoom` with winget, passing the signed config's `ZConfig` token through `--custom`, under its own 10-minute bound. Task 1 is the engine (config, winget, catalog, step, choices, report). Task 2 is the window (switch, strings, previews) and the docs.

**Tech Stack:** Windows PowerShell 5.1, WPF (toolbox), Pester 6 on the dev PC only.

**Spec:** `docs/specs/2026-10-22-zoom-app-design.md` (approved by Ben, Q56).

## Global Constraints
- Every `.ps1` is UTF-8 with BOM; Hebrew lives only in `src\Toolbox\Strings.ps1` (and `he` values of config.json). Logs and console text are ASCII.
- Never run winget, msiexec, an installer or setup.ps1 on the dev PC: tests mock `Invoke-External`, `Get-WingetPath` and the registry.
- `config.json`: `defaults.zoom` = `false`; `apps.zoom` = `{ "wingetId": "Zoom.Zoom", "custom": ["ZConfig=AU2_EnableAutoUpdate=true"] }`; `timeoutsMinutes.zoom` = `10`. No profile sets `zoom`.
- A custom token must match `^[A-Za-z0-9_]+=[A-Za-z0-9_=;]+$` (no quotes, no spaces). Tokens are joined with one space and passed as `--custom "<tokens>"`.
- Notes (yellow), exact text: `Zoom auto-update not set` (a token missing or failing the pattern; Zoom installs without it), `Zoom was already installed: auto-update not changed` (winget 0x8A150061). Activity lines: `Zoom installed`, `Zoom already installed`. A timed-out install is Failed with the message `Zoom install timed out`.
- Report: the Apps list names `Zoom`, read from the first Uninstall entry matching, in this order, `Zoom Workplace*`, `Zoom(64bit)*`, `Zoom (64-bit)*` (64-bit HKLM view first, as for every app).
- A profile that does not set `zoom` leaves the choice alone (Profile click, `New-DefaultChoices`, `Test-ProfileChanged`), as `windowsUpdate` does. Missing or non-bool `Zoom` means `$false`. The console fallback gets no line and no key.
- docs/testing.md: Zoom's real-machine items go in a new section **1.22 Zoom** (1.20 is drivers-only on main; 1.21 is taken by the repair branch).
- Conventional commits with the implementer's Co-Authored-By line; never push.

## Review Focus
1. **A customer's own Zoom already on the PC** (winget answers 0x8A150061): Done, the yellow "already installed" Note, the "already installed" activity line, no claim of a fresh install. Pinned in Task 1.
2. **A wrong auto-update token stalls msiexec** (help box): the run waits at most `timeoutsMinutes.zoom` (10), not 30, and the step is red `Zoom install timed out`. Pinned in Task 1.
3. **A config token with a quote, space or `&`** never reaches the command line (injection), and the step still installs Zoom with the Note. Pinned in Task 1.
4. **An old state.json without `Zoom`**, resumed by this version, plans no zoom step. Pinned in Task 1.
5. **Clicking a profile after switching Zoom on** keeps Zoom on, and the report's Profile line does not say "(changed)" for it. Pinned in Tasks 1 and 2.

### Task 1: The engine: config, winget custom args, the zoom step, Choices and the report

**Files:**
- Modify: `config/config.json`, `src/Steps/Winget.ps1`, `src/Steps/Apps.ps1`, `src/Engine/Catalog.ps1`, `src/Toolbox/SetupPlanner.ps1`, `src/UI/StartScreen.ps1` (`New-DefaultChoices`), `src/Report/Report.ps1`
- Test: `tests/Winget.Tests.ps1`, `tests/Apps.Tests.ps1` (Invoke-StepSevenZip and Get-InstalledAppVersions are tested there), `tests/Catalog.Tests.ps1`, `tests/Config.Tests.ps1`, `tests/SetupPlanner.Tests.ps1`, `tests/Toolbox.Tests.ps1` and `tests/Entry.Tests.ps1` (the Choices key lists gain `Zoom`)

**Interfaces:**
- Produces (Catalog.ps1): `Test-ZoomChosen -Choices <AllowNull object> -> bool`: `$true` only when Choices is an IDictionary whose `Zoom` is the bool `$true`. Every reader uses it.
- Produces (Catalog.ps1): a catalog entry `@{ Id = 'zoom'; Title = 'Zoom'; Short = 'Zoom'; Function = 'Invoke-StepZoom' }` right after `7zip`; `Get-StepPlan` includes it only when `Test-ZoomChosen`.
- Produces (Winget.ps1):
  - `Test-WingetCustomToken -Token <string> -> bool` (the pattern above).
  - `Get-WingetInstallArgs -Id -Source [-Custom <string[]>] -> string`: throws on any token that fails `Test-WingetCustomToken`; appends ` --custom "<tokens>"` only when at least one token is given.
  - `Invoke-WingetInstall -Id -Source -Context [-Custom <string[]>] [-TimeoutMinutes <double>]` and `Invoke-WingetOperation ... [-TimeoutMinutes <double>]`: the default timeout stays `timeoutsMinutes.default`. A Done from 0x8A150061 carries `Data = @{ AlreadyInstalled = $true }`; a timed-out run carries `Data = @{ TimedOut = $true }`.
- Produces (Apps.ps1): `Invoke-StepZoom -Context <hashtable> -> StepResult`.
- Produces (SetupPlanner.ps1):
  - `Get-SetupProfiles` items gain `Zoom` (`$null` when the entry has no bool `zoom`, else the bool).
  - `Get-ProfileChoices` adds `Zoom` only when the profile sets it.
  - `ConvertTo-ValidChoices` returns nine keys (adds `Zoom` = `Test-ZoomChosen`).
  - `Test-ProfileChanged` compares `Zoom` only when the profile sets it.
- Produces (StartScreen.ps1): `New-DefaultChoices` adds `Zoom` = `[bool]($Config.defaults.zoom -eq $true)`, then copies every key the default profile fills.
